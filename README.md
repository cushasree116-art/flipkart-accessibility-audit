# 🛒 Flipkart Accessibility & Lighthouse Audit

## 📖 Project Overview

This project is an accessibility, usability, and performance audit of the Flipkart website.

The project also contains a simple structure for client, server, testing, and documentation.

## 🎯 Objectives

- ♿ Check accessibility
- ⚡ Check performance
- ⌨️ Test keyboard navigation
- 🔎 Find accessibility issues
- 📸 Collect audit evidence
- 🏗️ Create project structure
