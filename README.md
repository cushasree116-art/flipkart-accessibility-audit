# 🛒 Flipkart Accessibility & Lighthouse Audit

## 📖 Project Overview

This project is an accessibility, usability, and performance audit of the Flipkart website.

The project also contains a simple project structure with client, server, test, and documentation folders.

## 🎯 Objectives

- ♿ Check website accessibility
- ⚡ Check website performance
- ⌨️ Test keyboard navigation
- 🔎 Find accessibility issues
- 📸 Collect audit evidence
- 🏗️ Create a basic project structure
- 🧪 Organize testing information

## 🛠️ Tools Used

- 🔎 WAVE
- 🚀 Google Lighthouse
- ⌨️ Keyboard Navigation
- 🌐 Web Browser
- 🐙 GitHub

## ⌨️ Keyboard Testing

Keyboard navigation was checked to verify that:

- ⌨️ Interactive elements can be reached using Tab.
- 👁️ Focus is clearly visible.
- 🔄 Shift + Tab moves backwards.
- 🔘 Buttons and links can be used with the keyboard.
- 🧭 Focus follows a logical order.
