# Keyboard Accessibility Test

## Purpose

A keyboard-only check was included as part of the accessibility review to understand whether important interactive elements can be reached and used without a mouse.

## Test Method

- Open the Flipkart website.
- Use the Tab key to move between interactive elements.
- Check whether the current element has a visible focus indicator.
- Use Enter or Space to activate the focused element.
- Observe whether the expected action takes place.

## Expected Result

Interactive elements should be reachable using the keyboard and should have a clear visible focus indicator. Buttons and links should respond correctly to keyboard activation.

## Evidence

The repository contains Flipkart screenshots under the evidence section.

Note: The uploaded Flipkart screenshots document the website interface. They do not by themselves prove keyboard focus or keyboard activation behavior.

## Conclusion

Keyboard accessibility should be verified using a physical keyboard on the website. Any issues found during the test should be recorded with a screenshot and added to the evidence folder.
